# 基础回归输入（不作为正式视觉起点）

这组 V9 文字样例用于工具测试与明确要求的极简任务。用户已否定其作为正式内容的美观度，正常生产请改用 [V10 完整设计资源](../editorial/README.md)，不直接把本组默认当成发布包。

每份 JSON 包含四页与独立发布文案，可用 `scripts/render-post.cjs` 导出 PNG、预览和可编辑源。它们是可复用的基础编排示例，不是已经发布的账号作品、客户案例或全自动艺术模板。

| 文件 | 内容与页面关系 | 主要验证 |
|---|---|---|
| [s1.json](s1.json) | 德语练习：封面—拆任务—加场景—回看 | 清单与步骤 |
| [s2.json](s2.json) | 家庭讨论：封面—偏好—变量—共同问题 | 暖色分组与分栏 |
| [s3.json](s3.json) | 咖啡馆文化：封面—物件—活动—偏好 | 文化解释与编辑式层级 |
| [s4.json](s4.json) | 资料阅读：封面—信息表—边界—待问事项 | 表格、原文/解释的区别 |
| [s5.json](s5.json) | 护理准备：封面—背景—分环节—下一步 | 任务与节点关系 |

S1/S2/S4/S5 是独立编写的方法示例，不含具体资格、当地报价、真实雇主、学校招生或客户经历。S3 的文化出处为 [奥地利 UNESCO 委员会条目](https://www.unesco.at/en/culture/intangible-cultural-heritage/inventory/element/article/viennese-coffee-house-culture)，2026-11-02 阅读；不把文化描述泛化为每家店的情况。再次发布时核对相关主张。

这些基础示例不要求图片。加入有使用权的图片或 AI 插画时，在对应页填写 image、imageLabel 与可选适配字段；不能用来源网页的图片代替授权素材。图片说明和重要出处需在成品中保留。实际素材、提示词与核验记录放在用户项目目录，不添加到公开示例。

在仓库根目录运行，例如：

```sh
node scripts/render-post.cjs --input assets/examples/s2.json --out output/family-s2-v01
```

调整内容后需重新检查。四页是这些测试示例的长度，不是账号的固定页数。浏览器测试覆盖五份文件的完整导出；它不自动完成事实与视觉审核，也不验证平台效果。
