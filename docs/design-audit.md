# 八方向八模板复查与修复

## 检查结论

八个信息方向是内容组织逻辑，用主问题、推进关系、证据和信息价值评估；八套模板是视觉资源，用层级、密度、图文关系、留白和一致性评估。两者不能用同一个“精致分数”概括。

| 范围 | 实际判断 | 本次处理 |
|---|---|---|
| T1—T3 | 已认可的成熟视觉基准，没必要为了变化重做 | 保留原图与参数，修复选择逻辑时不改这三套 |
| T4/T5 | 摄影与艺术画面有辨识度，适合观察和文化；不宜强装长条款 | 选择器考虑文字密度、素材和证据，允许换成宽栏模板 |
| T6 | 情境与对话适合轻量解释，长句或真实材料应另行分组 | 保留漫画语法，证据型任务不会自动强套漫画 |
| T7/T8 | 纯文字和资料结构是有意设计，但示例用法偏单一 | 保留原版，新增两套带图封面变体，内页内容保持一致 |
| 方向与模板匹配 | 原有推荐表可以指导Agent，但可执行约束不足 | 增加结构化简报、选择器、候选理由、素材缺口与近期模板处理 |
| 统一规范 | 同套底色、文字体系与页尾品牌已有基础 | 保留全篇规范，增加八套密集内容拒绝截断及变体内页保护回归 |

## 实际修复

新增select-design.cjs，按任务、密度、可用媒介、生成能力、证据与最近模板生成候选。明确选择优先；有冲突报告，不伪装为已解决。CLI只读取本地明确模板元数据，不上传或改写历史。

新增T7/T8带图封面，学习场景插画复用既有生成素材，资料整理照片为本次独立生成。每套只在确有任务处加图；真实原文、表格和重要条件仍优先清晰阅读。T7带图封面由拥挤的三窄栏改为一条全宽结论和两列短导读，避免句末孤字与碎读。

T7原短答案在高卡片里偏空，已补充问题拆分、资料记录、文件命名和再次确认的具体方法。两种封面版本同步更新内页；发布标题由“四个问题”修正为与实际六项问答一致，T8文案也明确区分表格和任务清单，避免标题/文案与图片不一致。

工具测试覆盖全部八套的过密内容拒绝、页尾署名、发布字段、图片与源文件一致性。两套带图变体核对内页字节与原版一致。图片存在不等于审美通过，实际预览仍需人工检查。

## 后续使用的真实边界

现在有更明确、可执行且可说明理由的辅助选择，Agent仍负责理解内容和验收成图。不是任意长文放进去都能自动美观，也没有验证64种搭配。缺证据、生成工具不可用或没有适合素材时，明确报告缺口，不宣称完成。视觉判断来自本次样稿检查，不代表已验证收藏、评论或获客效果。
