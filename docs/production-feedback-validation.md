# 生产记录与发布反馈升级：验证范围

本轮保留八个信息方向、八套模板及既有设计资源，更新生产与反馈工具；没有将真实账号导出、评论或每日历史放入仓库。

## 已验证

- 历史：自定义页的text/body/note、条目金额与单位参与比较；未知字段拒绝，逐页空文字有警告；输出位置和源图摘要可登记，修订保留原作品关系与旧记录。
- 运行环境：Node版本、Playwright与配置浏览器文件、Python版本有只读检查，不自动安装。
- 自定义交付：实际页面、源文件、素材、复制文案与最终PNG形成封存摘要；改源、错图、漏源、重复页面、目录链接和越界路径被拒绝。Windows CRLF文案按文本核对，摘要仍保留原始字节。
- 发布数据：使用临时虚构XLSX/CSV测试缺失与0、平台点击率、无单位时长、人工映射、重复快照、公式、工作表歧义、空格式列、非法指标及私有目录边界。
- 浏览器：运行了八模板、带图变体、三类题材和旧五类输入导出，检查可迁移源、局部修改保护、重复素材、品牌页尾与历史关联。
- 私有真实产物：在仓库外验证既有六页图文的六页全文、六张素材和成图对应；补全登记采用修订，不重绘图片、不删除旧记录。用户提供的导出表只在私有目录导入及复跑验证幂等。
- 文档：Skill入口通过结构检查，新增相对链接有效，改动文件检查未包含本机路径或用户实际统计。

## 可复跑命令

```sh
node scripts/check-env.cjs --mode core
npm test
python -m unittest discover -s tests -p test_import_xhs_metrics.py
```

完整浏览器回归需要设置RUN_RENDER_TESTS=1，并按环境配置PLAYWRIGHT_MODULE_PATH和BROWSER_EXECUTABLE。预检通过不保证浏览器成功启动或字体合适；实际渲染仍需检查。

## 不包含的验证

不声称所有S/T组合自动美观、未来模型绝不会违反规范、完整图片OCR、平台真机/上传审核、流量增长或有效客户归因。PNG头和摘要通过不替代解码、逐页目视及事实审核。导入工具不调用账号API、不自动计算跨快照增量、同龄队列或完播率。视频部分验证了制作交接规范，没有在本轮生成或重验全部历史成片。

README只列实际可用功能；本地安装版同步保留history.local.json及仓库外真实历史，不将生成状态改为已发布。
