# 八方向与八模板升级方案

## 信息逻辑、视觉与媒介分别管理

S1—S8涵盖清单、情境、观察、原文、比较、问答、主题叙事与文化溯源。S2/S3保留编号，校正名称，避免把插画和摄影混进内容逻辑。相邻方向按读者问题区分，不为了凑数量重复分类。

T1—T8分别承担陪伴叙事、雾蓝完整编辑、酒红精排、摄影杂志、艺术画册、轻漫画、问答专题与资料手册。保留T1—T3获认可基准，新增五套以构图、文字节奏、媒介和组件区分，不只换颜色。目录见assets/information-directions.json与assets/templates/catalog.json。

## 实际资源

八套可运行JSON共43页，每套配匹配的标题、正文和话题。T4使用三张不同的摄影感场景；T5/T6新增四张独立生成的水彩与漫画图，使用关联但不同的构图和动作。T7/T8以清楚的文字、解释和表格完成任务，不强制加图片。所有成图为1080×1440，配整套预览及可迁移源。

示例页数9/7/7/4/4/4/4/4只为展示组件。后续按内容密度、阅读任务与素材决定，不用稀疏标题撑页，也不为了塞满删掉受保护信息。方法型示例不继承原项目未核实的补助、门槛或服务承诺。

## 精排与内容质量

每页明确新增知识、观察、例子、解释或可使用字段。标题清楚、术语有解释、条件不藏小字。图文边界按网格对齐，长条件改宽栏或拆页，避免四窄栏碎读、孤字、币种拆分、字缝过大。留白承担信息分组和呼吸，不机械撑高或把结尾顶到底。

T7/T8首轮封面偏空，已补足主题相关导读；保留舒展空间，同时让读者在封面看到具体收获。正式稿仍须分别检查原图、手机阅读与整套节奏。自动无溢出不等于好看。

## 每页页尾署名

每套封面、全部内页、末页的页尾写“奥地利求学就业桔”，品牌字段拒绝误写“橘”或其他名称。署名用可控文字，和页码留足距离。渲染器核对实际DOM文字、字号与页尾安全位置，manifest记录每页brandFooter；包检查器要求结果完整。外部工具也执行相同规范，人工检查实际对比与遮挡。

## 流程与工具

范围/原稿保护→历史查询→资料与主张核验→内容对照与逐页任务→方向/模板/媒介选择→实际素材与排版→导出与文字/裁切/页尾检查→视觉阅读检查→发布字段核对→包完整性检查→本地版本登记→交付。

增加qa与dialogue组件，保留原渲染路径、版本保护、图片查重、字段预算和本地历史。固定品牌，维护可迁移输入。生成素材来源另记，成品不自动添加AI来源字样；实际发布由团队手动使用平台声明功能。私有记录与配置不进入公共更新。
