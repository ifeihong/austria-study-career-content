# 八个信息方向：先决定怎样讲清楚

信息方向负责内容逻辑，T1—T8模板负责视觉，照片/插画/漫画/图解属于媒介。S2与S3沿用编号，但分别更名为生活情境与细节观察，避免把画风写进信息分类。旧S1—S5输入仍兼容。

| ID | 信息方向 | 主要问题 | 典型结构 | 主题举例 | 常用模板 |
|---|---|---|---|---|---|
| S1 | 分类清单与实用指南 | 复杂事项怎样拆成可使用的项目 | 分类→优先级→具体字段→行动 | 预算、资料、准备事项 | T2 / T3 / T8 |
| S2 | 生活情境与选择讨论 | 一个具体处境下有哪些顾虑与选择 | 情境→不同顾虑→解释→选择 | 家庭讨论、学习安排、生活选择 | T1 / T6 |
| S3 | 细节观察与生活发现 | 画面里哪些细节值得看见 | 全景→物件/动作→关系→个人观察 | 城市日常、空间、通勤、工作体验 | T4 / T1 |
| S4 | 原文解读与证据说明 | 一份具体原文究竟说了什么 | 原文定位→含义→对象与条件→待确认项 | 学校通知、课程说明、条款、样本 | T8 / T2 / T3 |
| S5 | 路径比较与过程拆解 | 选项有何差异，步骤如何关联 | 对齐维度→比较→依赖关系→下一步 | 学习路径、准备顺序、不同选择 | T2 / T3 / T8 |
| S6 | 问题解答与概念辨析 | 这个问题的答案是什么，概念有何区别 | 具体问题→直接回答→解释/例子→适用条件 | 常见疑问、术语解释、误解澄清 | T7 / T3 |
| S7 | 主题深描与叙事推进 | 一个主题或过程如何逐步展开 | 主题入口→阶段/变化→解释→完整收束 | 护理学习主题、工作方式、生活过程 | T1 / T4 / T6 |
| S8 | 文化溯源与意义解释 | 一种现象从何而来，今天意味着什么 | 文化现象→来源与演变→当下实践→意义 | 咖啡馆文化、节日、艺术、生活习惯 | T5 / T4 / T7 |

## 相邻方向如何判断

- S1交付清楚、可使用的项目和字段；S5需要解释比较维度或步骤依赖，不只是多一张清单。
- S2由一个处境和选择驱动；S7沿主题或过程推进，不要求制造人物矛盾。
- S3先描述看见的细节；S8需要有来源地解释形成、演变或意义，不能凭画面编历史。
- S4围绕具体原文解释；S6围绕读者问题回答，可以综合多份证据。需要逐条读文件时优先S4。

每篇选一个主方向，必要时辅助一个；不为了凑编号把所有结构塞进一篇。新题可以继续使用旧方向。八方向不是八个人群，也不固定页数和发文比例。

## 每个方向做到实用

| 方向 | 实质价值 | 自然评论切口 | 常见失败与处理 |
|---|---|---|---|
| S1 | 可填写字段、分类和优先级 | 最想先整理哪一项 | 只有标题；补具体信息或合并页 |
| S2 | 理解处境和选择依据 | 更在意哪一个具体条件 | 虚构客户故事；改为明确的通用情境 |
| S3 | 空间、物件、动作与日常关系 | 你会留意哪个细节 | 泛化风景贴图；让每幅画面有观察任务 |
| S4 | 看懂原文位置、含义和条件 | 哪个术语还需要解释 | 截图太小或仿官方；保留出处并放大阅读 |
| S5 | 对齐维度、顺序、依赖关系 | 哪个环节最想展开 | 箭头暗示必然成功；区分整理顺序与法定流程 |
| S6 | 回答明确、概念区分、条件完整 | 下一篇回答哪个问题 | 故意不答诱导私信；先提供能公开说明的答案 |
| S7 | 逐层推进后的完整理解 | 想进一步了解哪个阶段 | 编亲历或成功案例；改用有来源的主题叙事 |
| S8 | 有依据的文化来历与当下意义 | 想追问哪个现象 | 用艺术画面当历史证据；解释回到可靠来源 |

生活文化允许以欣赏、理解和交流为目标，不强制导向业务。护理与家庭内容要区分起点、条件和负责主体，不以叙事、对话或画风包装结果承诺。没有真实案例也可生产资料解释、比较、观察和方法型内容。

## 媒介与整套一致性

真实日常与空间可用授权实拍或生成照片感；情境可用插画或漫画；比较和可填写资料用原生图解；特定机构/地点/文件的证据使用可核验且有权限的原素材。生成场景不充当客户、合作或政策证据。

同篇统一画布底色、文字层级、强调色与页尾署名；场景主图逐页独立，不用裁切、镜像、调色或换名伪装新图。近似画面仍人工看。关键中文、数字、品牌和来源采用可控排版。素材说明和手动平台声明提醒留在内部，成品不自动加AI来源字样；保留工具/平台已有强制标识。

Emoji辅助语气和识别，通常从每页0—2处试用，按内容调整。原文、费用和重要限制不夹装饰表情；检查导出后的缺字、基线与清晰度。没有帮助时可不用。
