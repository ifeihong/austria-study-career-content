# 视频制作交接与逐镜验收

用于把已核验主题交给 WorkBuddy、程序化动画或用户指定的实际可用工具。本文是交接格式与验收方法，不提供外部工具接口，也不表示已经制作出视频。成片范围以[视频交付](video-production.md)为准。

## 一条视频的最小简报

```text
作品ID / 版本 / 关联原作：
平台 / 画幅 / 目标时长 / 主要读者：
主要目标：吸引 / 保存 / 持续关注 / 具体提问（选一个）
唯一主问题 / 核心答案 / 适用条件：
开头承诺 / 第一幅画面正在发生什么：
本条新增信息 / 与旧稿的区别：
素材来源与许可 / 生成素材及声明记录：
实际制作工具 / 可用能力 / 待解决缺口：
音色 / 音乐方向与许可 / 已确认偏好：
结尾一句收束 / 一个可选交流问题：
交付：成片、封面、发布文案、字幕、工程与素材（按用户范围）：
```

主题先写成一句可回答的问题。开头给出具体场景、动作或选择，使后续故事能兑现承诺；不靠与正文无关的反转或泛泛旅游口号。文化和欣赏视频可止于理解与感受，不强行转为咨询。

## 逐段制作表

| 字段 | 必须明确的内容 |
|---|---|
| 镜号与起止 | 连续时间、预计持续时长；配音试读后锁定，不挤压关键条件 |
| 旁白 | 自然可说的具体句子，重音/停顿有作用；数字、单位与正式术语一致 |
| 画面任务 | 观众应看见、理解或感受到什么，不只填“奥地利风景” |
| 主体与动作 | 人物、道具、姿势、位置及发生的动作；与旁白逐一对应 |
| 场景与景别 | 室内/街道/交通工具、地面/座位基准、镜头方向和裁切重点 |
| 图层与运动 | 前/中/后景关系、各层独立运动、镜头运动目的；不是整图重复推拉 |
| 字幕和其他文字 | 具体字句、出现时间、层级和位置；避免字幕之外大量重复文案 |
| 声音 | 配音、音乐进入/退出、必要音效；音乐来源与许可明确 |
| 素材 | 文件或来源ID、授权/生成性质、需要后期可控排版的文字 |
| 保护区 | 脸、手、坐席、主要建筑、关键道具、字幕与平台界面遮挡区 |

文字和素材缺失时直接列缺口，不用假官方截图、虚构学校或他人视频补位。某镜因缺素材更改构图后，要重新核对旁白，不沿用已不匹配的旧配音。

## 拼贴动画模式

本账号已有拼贴项目的偏好可复用为该模式起点，不套用到全部视频：

- 人物、场景和道具画风一致，前景/中景/背景有真实层次关系；用动作、景别和视角推动场景，减少同图反复出现。
- 人物采用刚性左右/上下移动、小幅旋转或倾斜，不拉伸、扭曲身体。先锁定地面、脚底或坐席接触点，再做微动；运动不能让人物飘离接触面。
- 在公交车内选择坐姿或合理站姿；坐姿臀部实际落在座位上，脚与车厢空间合理。道路场景按叙事选择人行道或合理站位，不为居中把人物放进不合理位置。
- 用户要求每镜有人时逐镜执行，并为相应环境配正确动作；不把该项目要求扩大为所有文化解释或材料演示视频。
- 少量重点文字服务叙事，不遮住脸、手和关键场景，也不紧贴字幕或画面上沿。字幕样式与水平位置一致，按该项目要求居中；优先一行，长句拆成连续出现的单行cue，句尾不放标点。

## 先做内部代表段，再扩展

选开头、最复杂人物场景和文字最密集镜头试合成；新声音用10—15秒代表内容检查呼吸感、停顿、重音、品牌/德文读音及配乐进入感。用户已有确认素材就沿用，不为例行流程再问一次。

检查后扩展全片；如果问题来自人物与背景关系，应更换姿势/场景或重新定位，不能只对全部人物统一放大。配乐音量以手机听清旁白又有音乐作用为准，不靠全程抬高音量掩盖缺乏旋律或不合情绪。

## 交付检查

1. 逐镜对照旁白与画面：此时说到的人、动作、物件和关键条件是否真的出现。
2. 检查最终裁切和文字遮挡：人物比例、地面/坐席接触、地标主体及平台安全区合理。
3. 看开头到结尾是否围绕同一主问题；跨镜叙事连续，不只是逐页切换图片。
4. 实际播放检查配音与字幕同步、术语和数字、停顿与音乐响度；解码成功不等于声音自然或美观验收。
5. 封面与视频同主题、同画风，标题手机小图可读；用户要求时分别制作真实3:4和4:3构图，不只裁掉内容凑比例。
6. 保留对应标题、正文、话题和版本。公开成片不额外烧录AI来源标签；内部逐镜记录、团队平台声明和必要身份说明按[公开表达规范](public-expression-rules.md)执行。

只完成简报时称“制作简报”；交接给工具不等于成片完成；未实际播放或审听不得声称已经通过整片检查。发布和联系读者仍需用户授权。
