# 正式图文的视觉制作与验收

## 质量基准与默认路径

用户明确偏好早期封面 DEMO 的画面与设计完成度，并否定 V9 基础文字示例作为正式内容的视觉标准。后续正式图文默认从 [V10 三套完整样稿](../assets/editorial/README.md) 的设计方法开始，结合当次主题另行创作；旧 [基础示例](../assets/examples/README.md) 仅用于输入、回归测试和明确要求的极简文稿，不能自动当作最终视觉方案。

保留温暖、清楚、有依据的品牌气质，不要求所有题材使用同一种颜色或布局。不靠加边框、调底色、堆 emoji 掩盖内容单薄；也不把“没有实拍和客户案例”理解为不要视觉素材。可用有内部来源记录的 AI 图片、独立图解或有使用权的资产，不能伪装亲历。

## 制作前的两个检查

**能力与素材检查**：当前能否生成/使用图片、可否排版导出、有什么已经可用的品牌资产。缺少实拍不阻塞资料型创作；用户明确要插画时，不能悄悄改成交纯文字并称为完成。无法实现的环节及时说明，先完成可独立完成的部分。

**事实与文案初审**：先确定本篇结论、重要限制、公开用词及出处，再画图。关键事实未确认时先删改或换题；不能把大量待核验内容做成漂亮图片后再想办法补免责声明。

## 从内容到页面

已有长原稿先按[原稿保留模式](manuscript-fidelity.md)建立内容对照，再分配页面。当前优先制作资源增加[八套设计模板](selected-templates.md)；原V10三套题材样稿仍可使用，两者不能混称为同一批模板。精排细节及最终包检查见[质量检查](production-quality.md)。

先写出本篇主要收获，并为每页分配任务。按实际需要采用封面、场景解释、对照、图解、表格、工作表、步骤、收束等角色，不固定页数。

每页内部简报可记录：**读者需要看懂什么 / 上版文字 / 图片任务 / 媒介与选择理由 / 主体、动作、景别 / 素材性质与出处 / 与上一页相比新增什么**。这是制作记录，不塞进发布正文。

- 只有泛泛短句、没有信息增量：补具体解释或例子；仍不足则合并页面。
- 一页承载多个无关问题：删减或拆页，不能用缩小字号解决。
- 少字氛围页：可以保留，但应有实际主画面、情绪或叙事任务，不是把文字顶在上方、留下大片无作用空白。
- 不为了填版加入空泛总结、重复提醒、未经核验数字或多余销售结尾。

## 选用构图，而非套同一张卡片

| 页面角色 | 主要方法 | 内置可用布局 |
|---|---|---|
| 图片主导封面 | 一个能支撑标题的画面，大标题与简洁辅助信息；图中留出阅读空间 | `poster` |
| 图片解释页 | 一幅有明确观察任务的图，下方用短段落解释，使用与封面关联但不同的新画面，突出本页观察重点 | `feature` |
| 对照与分类 | 对齐维度与文字长度，读者一眼知道分成什么、为何不同 | `cards`、`split` |
| 工作表与资料组织 | 有实质字段、示例内容或阅读方法；自制表不伪装官方文件 | `worksheet` |
| 任务与过程 | 说明顺序、依赖或并行关系，节点各有实质任务 | `journey` |

上述布局使用 `design: "editorial"`。它们是可控的制作资源，不是所有设计的上限；复杂场景、自由构图或证据标注可以用其他合适工具。用户已经确认的图片与内页优先保留。

## 图片、文字与视觉节奏

先按 [媒介选择表](xiaohongshu-styles.md) 决定图片承担的任务。场景页用照片感、插画或漫画帮助代入，数据和操作页用清晰的原生图解，证据页核对资料来源与使用权。生成或取得素材后检查成图，再添加品牌、关键中文、数字、必要的事实出处。

例如，一篇家庭赴奥准备可用街区照片感全景做封面、窗边办公近景解释工作安排、桌面静物与计算卡说明月收入、住宅背影引出住房材料，末页用可截图的讨论表。场景素材与数据各有任务，整套沿用同一个视觉系统。

**同套画布底色默认统一。** 从封面到末页使用同一个背景色，页面节奏交给配图、构图、卡片和强调色。不同套图文可按主题另选底色。内置渲染器在整套的 `theme.background` 中设置画布颜色，避免页级风格切换带出不同底色。交付前在整套预览中检查每页四周留白的颜色，尤其留意封面、解释页和表格页。用户明确指定的系列变色设计按其要求执行。

同一篇保持文字层级、边距、色彩角色与署名一致。封面可强视觉，解释页提供信息，对照和工作表强调阅读，结尾自然收束。同一套图文中的生成主图不得重复使用同一张图片，包括非连续页面。裁切、放大、镜像、调色、加字或换文件名不算新图；不能用这些操作绕过要求。品牌 Logo、页码与装饰图标不属于主图。官方截图的必要对照或证据细节可以复用，但需明确标注其证据任务，不当作新场景。

### 同套配图：统一风格，逐页延伸

排版前建立配图清单，记录：页码、图的任务、媒介与选择理由、场景和动作、景别与视角、沿用的风格元素、新增的视觉信息、素材性质、来源或生成提示词、最终文件。按实际图片页数准备独立素材，不强制每页配图。

- **保持一致**：媒介质感、色彩、光线和氛围；确有连续叙事时保持虚构人物特征、服装或场景元素。不能为了统一而机械重复同一构图。
- **逐页变化**：按本页内容变换动作、物件组合、空间或观察角度，至少带来一个实质场景/叙事变化，并配合景别或构图变化。仅生成肉眼近乎一样的变体也应重做。
- **可用组合**：咖啡馆全景 → 报纸架与桌椅 → 阅读动作；家庭共同规划 → 讨论各自需求；职业准备 → 学习任务 → 材料整理。变化必须支撑当页内容，不为凑图编造工作、客户或在地经历。
- **生成方式**：首图作为风格参考，后续分别描述需要保留的元素和必须变化的场景/动作/构图；每张独立生成、检查并保存。工具不可用时说明缺口，不能回退成重复同图而宣称完成。
- **验收方式**：查看整套配图缩略图和原图，确认既能看出同一系列，又不会让读者觉得反复看到同一张图。文件内容哈希可发现完全重复，不能替代对近似画面的人工判断。

逐页验收时问一句：换掉这张图，会丢失哪一点理解或场景信息？若替换成通用风景也成立，就重选画面或直接用清单。对照表检查读者能否截图并实际使用，资料页复核出处、关键条件与敏感信息。结合本地历史比较问题、结论、页内任务和主画面，换画风属于视觉调整，内容增量看新增解释或可执行信息。

图文成品不自动加 AI 来源提示。配图清单和手动声明提醒与成品分开，按[素材记录与手动声明](xiaohongshu-publish-fields.md#素材记录与手动声明)处理。地点未核实不标真实店铺或医院；人物不是客户、从业者见证或合作证明。保持源图、提示词与素材对应关系。

字号与密度先按制作指南试排，再在 360—420 像素宽实看。重要条件不藏小字；没有字号缺陷也可能读起来吃力，应根据文本量、行长和分组一起调整。不设置统一内容占比或强制每页配图。

## 两项验收分别通过

**内容验收**：标题被兑现；有具体信息或感受价值；事实、条件与出处对应；没有机械重复、假案例或超出资料的承诺。内容不够具体时回到稿件修改，不能只靠图片补救。

**视觉验收**：逐张看原图和手机宽度，检查主次、构图、图片语义、裁切、可读性、密度与来源位置；再看整套节奏。大片无作用空白、内页没有新增信息、画面与主题无关、只有封面好看而内页草率，都需要返工。

自动检测只检查其能验证的事项。无溢出、PNG 存在和标题像素可见，不证明美观、内容完整或传播有效。参考样稿是设计起点，不是对所有主题的已验证保证。

修改后重新导出受影响页，核对发布文案与其他页面的一致性。局部修改及未改页保护仍按 [版本规则](revision-and-private-data.md) 执行；交付状态按实际检查程度说明，不把本地成品称为已上传。


## 每页页尾署名

封面、全部内页和末页页尾保留“奥地利求学就业桔”，保留“桔”字。署名与页码对齐并留距离，避免贴边、压图或过小。内置渲染器逐页检查品牌文字、页尾安全位置和至少22px字号，manifest记录brandFooter结果；这是技术下限，实际以手机阅读检查为准。外部工具和自定义版式同样执行。
