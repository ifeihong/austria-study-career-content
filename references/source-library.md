# 国内外内容参考来源库

建库与本轮复核：2026-11-02。用于选题、表达观察与寻找原始出处，不是素材转载授权、实时政策库或账号效果排名。下列“借鉴”均为编辑建议，不代表已证明其流量或咨询效果。原创案例短缺时，从这些来源获取问题和知识，再独立组织内容。

## 如何使用与维护

先按主题选 1—3 个相关来源，打开本次要参考的实际页面/作品，记录作品直达链接、显示日期、可见范围和访问日期。账号入口确认不等于看过其帖子；搜索摘要不算全文。旧的可读页面也可能是缓存，不冒充最新动态。

- **A1 实质正文可读**：取得具体文章或有实质信息的专题正文，只使用实际读到的部分。
- **A2 部分可读**：取得主页片段、节目介绍或部分文字；不能当作全文、完整转录或视频已观看。

本库现保留 **11 项可读来源：9 项 A1、2 项 A2**。来源 ID 保持稳定，不因删除入口而重新编号。只有链接、导航、登录页、空壳频道或搜索摘要的，不算可读来源，不纳入数量。

同机构的不同平台不是多个独立证据。页面可读也不表示其资讯实时有效；历史作品适合研究结构和文化背景，时效事实发布前另核对。机构的旅游宣传不能证明长期居住、工作待遇或个人资格。

## 不可读时怎样处理

原页不能读时，最多继续核对该机构官网、另一官方平台或一篇具体文章，共 2—3 个合理替代入口；不反复重试同一受限平台，不绕过登录/付费限制。至少找到一份有内容、与主题相关的正文，才保留该机构作为活跃来源。

有替代正文：以可读的直达页面作为主入口，标明其实际语言和范围，不声称已经读过原平台。只有零散片段：限于结构灵感，不支持完整事实结论。全部不可读或仅有不相关内容：移出活跃库；失败记录放维护报告，不要求创作时重复加载。以后实际恢复可读，再带内容样本重新纳入。

本次已将维也纳旅游局小红书、Instagram、YouTube，以及使馆文化处哔哩哔哩、微博的不可读入口移除。维也纳旅游局改用 CN05、REF02 和 INT04；文化处改用 REF07。不是删除机构，也不是把官网内容冒充该平台的内容。

### CN01 / 维也纳旅游局微博

- [账号](https://www.weibo.com/welcometovienna)；[机构官网的社交入口](https://www.wien.info/en/vienna-info-on-social-media-363278)。状态 **A2：主页正文/片段可读**；不是当日实时后台数据。
- 观察：主页包含文化地点、季节题材和活动信息。借鉴“具体地点或物件切入”；不照搬原句、活动数字、排名或奖励互动。
- 适配：文化认识、城市印象、周末生活。旅游便利不能推导为居民待遇。关注数、点赞数与年份不完整的日期不纳入效果判断。

### CN05 / 维也纳旅游局：中文博物馆区专题

- [聚会地点 博物馆区](https://www.wien.info/zh/艺术和文化/聚会地点-博物馆区-600782)。状态 **A1：中文实质正文可读**，为该机构受限社交平台的替代，不声称是小红书笔记。
- 实际取得：将文化场所与餐饮、空间等日常元素放在同一主题里。可衍生“文化空间也能怎样连接日常生活”的选题，避免只罗列打卡地点。
- 边界：不照搬面积、排名、营业时间与设施承诺，不直接使用页面图片。具体事实、开放与许可按任务核验。

## 补充来源的准入条件

维护时记录：来源 ID、名称、平台/地区/语言、链接、发布主体、主题、正文访问状态、具体观察、可借鉴机制、改写切口、禁用推导、访问日期、署名/许可与更新触发条件。

只保存短摘要、分析和必要出处，不建立整篇搬运库，不越过登录、付费或平台访问限制。普通创作发现好来源时，在用户项目的来源记录中暂存；仅在用户要求维护 Skill 时补入本库。没有调度与授权，本库不会自动爬取、后台监测或保证不断更新。
