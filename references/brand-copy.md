# 品牌文案执行标准

## 声音与篇幅

像愿意把事情讲具体的职业与家庭规划顾问：自然、尊重、有依据。温暖来自理解顾虑，专业来自解释条件与步骤。避免假装亲身经历、反复喊口号或用肯定语气掩盖未知。

每篇先确定一个中心判断，段落围绕该判断推进。短句用于重点，完整解释放在需要处；不要把所有句子都改成碎片式标语。

## 改写示例

| 场景 | 不推荐 | 推荐方向 |
|---|---|---|
| 开头 | “在全球化浪潮下，越来越多人选择欧洲发展。” | “考虑赴奥工作，先把自己的学历、资格、语言和时间安排整理出来。” |
| 吸引注意 | “普通人逆袭的最后机会！” | “这项准备会占用多少时间，决定前值得先算清。” |
| 讲述困难 | “德语没有你想的难。” | “先拆成可完成的学习任务，再为需要反复练习的部分留时间。” |
| 解释术语 | 直接堆德文缩写和政策名称 | 先用一句中文说明本篇要讨论的环节，再保留必要的正式名称与适用范围 |
| 服务表达 | “我们全程包办，你只管出发。” | “先明确哪些信息梳理和准备工作在服务范围内，哪些环节由相应主体负责。” |
| 结尾 | “赶紧私信，错过再等一年！” | “把还没确认的项目单独列出来，再决定下一步先问谁。” |

示例说明表达方法，不替代事实核验。不得为了简洁省略会影响理解的资格、年份或例外。

## 正向生活与文化表达

可以写出好看、松弛、好奇与向往，尽量落在画面、动作和细节上。将审美偏好、个人体验、可观察事实和制度条件分开，不把“这个下午很惬意”推导成“所有工作都轻松”。

示例方向：“一个空闲下午，你更想在公园走走，还是找间咖啡馆坐坐？”允许纯兴趣讨论。“奥地利人人不加班，来了就能享受人生”则属于没有依据的普遍承诺。示例是创作方法，不代表相关场景或待遇已核实。

不为每篇美好展示机械补一段负面提醒；只保留会影响理解的条件。具体栏目与评论方法见 [生活文化与互动](lifestyle-culture-engagement.md)。

## 知识型公开口径

封面、简介与日常推广优先准确的学习、德语、职业准备、教育和家庭生活表达，不把“移民”“永居”“身份”作为结果口号。涉及真实政策或客户咨询时仍需正确名称与完整条件，不把商业服务伪装为官方或无商业目的的百科。避词不能保证流量；不得用谐音和暗号规避规则。见 [定位与咨询衔接](consultation-and-positioning.md)。

## 按任务调整语气

- 清单：动词具体，分类平行，条目不重复。
- 生活与文化：可以温暖、有画面、有审美，不把所有主题都写成准备课；不替家庭或读者做价值判断。
- 材料解读：区分原文与解释，解释比术语更重要，不装成官方通知。
- 视频旁白：自然可说、可停顿，避免书面长定语；字幕不承担旁白没解释的核心条件。
- 数字人：不以虚拟身份冒充真实从业经历或个人见证。

## 标题、正文和行动的关系

标题的承诺必须在内容中回答；封面简化表达但不改变含义。正文补前提、解释和使用方法，不把图片逐字复述。

结尾只给与本篇相关的一步：填写、查询、讨论、整理，或在资料和服务已存在时领取与预约。不能所有内容都以咨询广告结尾。

## 改稿检查

读一遍并删除：无依据的“越来越多”“大家都知道”、抽象的“全面赋能”、反复出现的“首先其次最后”、没有新信息的总结、固定重复的开场与结尾。

不要把“有温度”“高端”“专业”当作唯一修改指令。将其转为可观察变化，例如换成家庭具体问题、减少术语、补一项适用条件、压缩重复段落。

保留用户已经确认的原句、事实、语气和必要关键词。风格建议不自动授权重写整篇。
