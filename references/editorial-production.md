# 素材有限时的编辑生产方法

## 默认生产模式

本品牌现阶段不依赖自有实拍、采访或客户成功案例。优先采用公开来源研究、知识解释、原生图解、明确标识的 AI 插画及不涉及真实人物的说明型情境。原创在于问题、分析、叙事和设计，不要求假装亲历。只有用户主动提供真实且可用的资料时，才启用案例/实拍，不把它们设为验收必选项。

缺少真实素材时，不写“我在当地”“我们客户”“今天带你实探”。假设情境只解释一般问题，不虚构姓名、获批过程、评价或故事来暗示已有业绩。不要把团队素材短缺作为对外文章的固定开场。

## 从参考到独立内容

1. 从 [来源库](source-library.md) 按当前主题选择少量匹配来源；先确认实际能读到什么。
2. 分开记三件事：参考内容提出的问题、可借鉴的表达机制、需要另查的事实。不把“受欢迎的说法”当真。
3. 换成目标读者的真实问题，独立决定结论、结构和画面。无法指出新增解释或使用价值时，放弃这次改编。
4. 核对核心事实，重新写作，不按原段落换同义词，不逐句翻译，不复刻标志性封面/镜头组合。
5. 审核标题、图片、正文是否兑现同一承诺。来源/授权记录留在项目里，公开出处简洁呈现。

参考账号可提供灵感，官方原文可提供对应事实，素材许可决定能否使用图片/音频/视频。三者不能互相替代。署名也不等于取得转载权；未取得素材使用权时改用自己的排版、图解或有标识的 AI 场景。涉及政策的社交帖先回到主管原文，不复制旧门槛。

## 内容选型：根据价值选择，不固定比例

| 类型 | 单篇需要带走什么 | 不靠案例也能制作的方式 |
|---|---|---|
| 美好生活/感受 | 一个具体印象或偏好 | 有来源的文化细节、授权图片或 AI 场景示意、少字组图 |
| 文化解释 | 看懂一个物件、习惯或地方背景 | 原始文化出处 + 独立解释 + 简单图解 |
| 学习与准备 | 完成一项具体小任务 | 独立编写的练习、自查表、资料阅读方法 |
| 职业认识 | 理解职责、岗位与生活安排的一个区别 | 官方职业说明、岗位信息阅读，不编在岗故事 |
| 家庭讨论 | 家人能一起确认一件事 | 目标讨论、资料比较、预算变量，不做资格判断 |
| 时效信息 | 知道什么发生了变化、谁需要关注 | 当次原始通知、旧新差异、明确日期；未核实不做“最新提醒” |

有依据的正向优势可以突出，不机械加负面段落。专业主题要有实质回答：不能每次都仅写“先核对、再确认、因人而异”。资料不足时，给可执行的核对项目、对应机构入口或明确的问题；仍无信息增量就换题。

## 专题系列与批次去重

按“专题问题—本篇新增信息—后续可延伸问题”组织系列，不设置固定更新频率。每篇独立兑现标题；不把关键答案扣到下一篇，也不只换封面和人群称谓重复清单。

例如“认识咖啡馆文化”可依次研究物件、空间、不同活动偏好；“护理准备”可研究背景整理、术语、岗位信息阅读；“家庭生活”可研究共同目标、预算、日常活动半径。它们是选题关系，不是已经核验的事实稿。

有历史记录时比较主题、主问题、结论、证据、结构和主画面；保留变化理由。没有历史作品时只做本批次去重，不虚构全账号检索结果。

## 搜索表达与 SEO/GEO

先判断读者在“想了解是什么、如何做、比较选择、核对当前变化”中的哪一种需求。每篇选择一个主问题，自然写清奥地利/城市、人群与事项；真实相关才加入标题和话题，不机械重复品牌名或身份词。

- 标题给准确问题，开头尽快回答；正文再解释适用对象和条件。生活氛围稿可以从场景进入，不强制变 FAQ。
- 术语首次出现时解释，必要时保留中文、德文/英文与缩写，后续称谓一致。例如 Wien 与维也纳属于同一实体；不是把不同许可统一成一个“项目”。
- 一段可独立理解的解释包含对象、结论、条件和来源，方便阅读与引用；不为适配检索删掉限制。
- 平台内搜索表达、公开网页的 SEO、生成式回答的可引用性分别判断。只有图片不代表搜索系统一定能读到，正文保留必要文字；没有公开网页时不承诺网页收录或 AI 引用。
- 未观察搜索结果或后台数据的词只标“候选词”，不写热搜、搜索量或竞争度。要研究当前热度时另查，不能把模型猜测当数据。
- README 的说明和导航服务于发现、理解与使用，不堆关键词，不保证排名。平台限额、AI 标识和导流规则按当前任务核查，不把历史规则写死。

## 评论转内容与自然咨询

| 实际问题类型 | 建议处理 | 边界 |
|---|---|---|
| 原稿没讲清 | 先给准确补充或纠正，再考虑修订 | 不将误解当作互动成功 |
| 对文化/场景好奇 | 记录延伸问题，独立做续篇 | 不强推资料或咨询 |
| 学习/准备求助 | 给一项能做的小任务或查询入口 | 不凭留言判断资格 |
| 个案与服务提问 | 草拟如实的范围说明，按必要程度了解阶段 | 不公开索取整套材料，不自动私信 |
| 不同观点或质疑 | 区分事实争议与偏好，核对出处 | 不虚构支持评论，不争吵或删改事实 |

可以为确实相关的内容准备一条低负担提问，或者没有提问。资料领取只在资料真实存在时使用。服务介绍应真实说明商业性质、范围和费用，不能把重要限制拖到付费后才披露。公开低销售感不等于对客户隐瞒实际服务。

## 小任务与实用内容种子

- 德语：把学习词汇放进一个日常沟通任务，独立编写练习；德语含义与奥地利用法核对，不冒充语言课程或证书保证。
- 护理：教读者找出岗位说明中的职责、工时、资格和待问问题；不生成患者医嘱、临床治疗建议或假合同作证据。
- 家庭：把预算中的周期、支付时间、包含项和不确定项列清；无价格来源时不给“真实花费”。
- 教育：帮助理解学校原文的对象、阶段、材料与日期；没有项目依据不扩大成全品类留学申请推荐。

## 验收真实任务

至少覆盖：纯生活欣赏、文化解释、在读护理准备、家庭预算、专业资料解读、缺少素材、评论衍生、只改一页。检查是否有独立信息价值、准确出处、读者能理解的条件、自然语气与可用产物。

验收不是统一措辞、页数或配色。制作测试证明导出能力；视觉检查证明对应页面的可读性；内容审核证明对应主张；真实效果只能由实际发布数据支持。记录具体失败并修正，不为凑合格率给主观精确分数。
