# 受众判断与选题设计

## 先明确读者正在做哪个决定

生活文化内容还可先判断读者好奇什么，不要求每篇都对应申请或职业决定。专项方法见 [生活文化与互动](lifestyle-culture-engagement.md)。

根据用户简报与已有素材填写：主线、背景、准备阶段、主要顾虑、已知信息、本篇帮助完成的一个动作。缺少背景时说明暂定读者，不推断年龄、收入或学历，不把示例当真实人群数据。

| 主线与阶段 | 值得解决的问题 | 内容深度与合适形式 |
|---|---|---|
| 兴趣 / 生活与文化 | 哪些场景、习惯或工作生活体验值得了解 | 画面叙事、文化细节、偏好交流，不强制加入准备清单 |
| 护理 / 相关专业在读 | 现在能做什么、哪些必须等毕业或资格齐备 | 学习/实习安排、语言启蒙、材料记录与家长沟通，不承诺立即就业 |
| 护理 / 已毕业待衔接 | 学历与资格缺口、语言、补修和岗位如何分开核对 | 背景分流、路线说明与阶段任务，不把所有学生归同一路径 |
| 护理 / 初步了解 | 应从哪些方面判断是否值得继续了解 | 自查问题、概念区别，避免一上来堆办理材料 |
| 护理 / 语言准备 | 当前学习安排与职业目标如何衔接 | 阶段任务、工作场景、学习记录，核验具体门槛 |
| 护理 / 材料与资格衔接 | 有哪些环节、材料和负责主体需要分别确认 | 材料解读、核验清单与依赖关系 |
| 护理 / 岗位比较与落地 | 合同、职责、工时和生活安排如何一起看 | 对齐比较维度、脱敏样本与实际场景 |
| 家庭 / 目标讨论 | 家人各自看重什么，约束在哪里 | 讨论框架、选择问题与标注的情境 |
| 家庭 / 预算与教育准备 | 哪些信息会改变住房、转学和现金流安排 | 预算变量、资料核对与时间安排 |
| 家庭 / 申请准备与安家 | 谁负责确认什么，先后顺序是什么 | 待办清单、来源解读、办事流程 |
| 共性 / 信息辨别 | 怎样识别一个说法的适用范围 | 证据阅读、术语解释、比较框架 |

这些是编辑分层，不是资格筛选规则。例如“零基础学德语”和“已有考试成绩但担心工作沟通”可采用不同选题，不因此推断谁一定可以就业。

## 从主题生成有区别的角度

将宽泛主题变为“人群 + 当前情境 + 一个具体问题或感受”。生活文化内容还可以围绕一段有主题的画面或一个值得认识的细节展开。然后在材料、选择、时间、账本、场景、误会与证据解读中选真正不同的切口。

例如主题“德语准备”可以拆为：

- 初步了解者：决定开始前，先确认哪些学习和时间条件？
- 正在学习者：怎样把本周学习任务写得具体？
- 已有成绩者：考试与工作沟通分别该准备哪些问题？

上述为选题示例，不是具体资格标准。不要把同一张清单换标题后重复交付。

## 读者痛点的使用

学生可关注语言时间投入、学历衔接、总成本、家长信任、岗位真实职责及落地支持。家庭可关注教育选择、持续现金流、工作约束、夫妻目标、生活适应与多年维护。它们是需要访谈验证的工作假设，不是已证实的人群统计。具体内部服务设计从用户私有简报读取，不写入公开案例。

内容用具体问题帮助读者自我识别，不靠隐藏词、焦虑或夸张收益吸引不匹配咨询。取得背景也不等于完成资格判断。

## 选择优先级

按以下判断择优，给简短理由，不使用没有数据依据的精确分数：

1. 与品牌内容方向和读者兴趣是否相关；不要求每篇直接对应业务办理。
2. 有无足够的事实、材料或可兑现的方法。
3. 看完是否有具体印象、新认识、讨论意愿或可执行收获。
4. 相比已有作品，是否增加新信息或新视角。
5. 制作成本是否与本次目标匹配。

没有证据支持的高收益话题，不因“吸引人”而优先。证据不足可以先产出自查或准备框架。

## 内容记录与去重

用户提供历史作品后，比较“主读者 / 阶段 / 核心问题 / 核心结论 / 结构 / 主要画面”，不要只比较标题相似度。用本地内容记录保存上述字段、作品 ID、版本、发布日期及实际反馈；记录属于用户项目资料，不写入公开 Skill。

区分重复与有价值的更新：新来源、新适用条件、新受众、新问题可以形成更新，需写明变化。没有历史记录时说明本次只能在已见内容中去重，不声称全账号已去重。

生活文化选题允许用具体细节形成吸引力，正向优势有依据，评论问题贴题且容易回答；不把强咨询意向作为所有选题的必选条件。

多选题交付可包含：推荐顺序、主读者与阶段、问题、标题方向、创意结构、所需证据和下一步。用户要成稿时直接展开最佳方向，不停在选题表。
