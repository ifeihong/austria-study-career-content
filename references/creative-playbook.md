# 内容生成与创意指南

## 最小创作简报

优先从用户原话提取，缺项可合理默认，不要让每次创作变成问卷：

“给谁看 / 眼前的具体问题 / 看完能判断或完成什么 / 平台与形式 / 已有事实和素材 / 本条希望的下一步”。

用户只要标题或创意时，不展开完整脚本。用户要可直接制作的稿件时，不停留在概念提案。

选题先按 [受众与选题](audience-and-topics.md) 判断准备阶段和内容差异；文案按需参考 [品牌文案执行标准](brand-copy.md)。

生活、文化与工作体验可按 [生活文化与互动](lifestyle-culture-engagement.md) 选择感受、了解、讨论或规划衔接目标，不要求每次给出办理步骤。

## 创意应改变切口，而非只换标题

围绕同一主题，从真正不同的角度中选用：

| 切口 | 适合的主题 | 表现方式 |
|---|---|---|
| 一个生活片段或文化细节 | 日常氛围、习惯、艺术与生活方式 | 场景叙事、主题组图、具体观察和自然讨论 |
| 一个具体决定 | 是否开始学德语、何时准备转学 | 决策分叉、先问后答 |
| 两份材料的区别 | 资格证与认定结果、合同不同条目 | 实物标注、并排比较 |
| 一笔账 | 家庭现金流、工资构成 | 逐项拆账，明确假设 |
| 一段准备过程 | 材料、学习、等待 | 时间轴、任务便签、过程记录 |
| 一个常见误会 | 把入学当就业、把居留当工作许可 | 温和纠偏，给核对方法 |
| 一张清单 | 第一周准备、咨询前整理 | 分组勾选、优先级 |
| 一次家庭讨论 | 夫妻关注不同、孩子衔接 | 明确标注的虚构情境，呈现不同顾虑 |
| 一份证据怎么读 | 政策页面、工资单、学校通知 | 截图放大、出处解释、限制条件 |

不要把护理题机械改成家庭题就算创意，不把奥地利风景当作所有内容的主要信息画面。

### 选题输出

用户要多个选题时，可用表格：主线、目标读者、具体问题、切口、建议标题、适合形式、所需证据。按需求控制列数。

若是同一主题的创意提案，默认给三个方向：切口、开场、核心信息、视觉方法及适用原因。推荐一个并说明理由；明确要成稿时选定后直接完成，不等待无必要的确认。

### 标题与开场

标题承诺必须能在正文兑现。用具体人群、场景、疑问或比较，不编造“90%的人”“内部消息”“最后窗口”。

同一主题的三个标题应分别改变读者关注点，例如“赴奥准备，先整理哪几份资料？”“有护理资格证后，还需要核对什么？”“开始备考前，先把自己的背景列清楚”。这些是结构示例，不含资格判断。

开场可以是一句提问、一个材料特写、一个待办动作或一个经过标注的情境。尽快进入主题，不堆“你知道吗、震惊了、千万别”。

## 小红书图文成稿

具体工作流见 [小红书完整制作指南](xiaohongshu-production.md)。默认完成封面和全部内页图片、发布标题正文及话题、整套预览，并保留可编辑源文件。图片导出后做逐页与手机尺寸检查，不能把文案和画面建议称为完整成品。

用户明确只要选题、文案或方案时按该范围交付。页数与结构由信息决定，不固定六页；图文统一视觉标准，同时允许不同叙事结构与构图。

## 无露脸短视频成稿

脚本、可发布成片与可编辑工程的交付边界及检查见 [视频交付](video-production.md)。

默认 45 秒，可按用户指定平台、深度与时长调整。抖音可扩展为 45—90 秒，视频号专题可扩展为 2—3 分钟。这些是制作参考，不是固定规则。

逐段表格字段：时间、旁白、画面/动作、屏幕字幕、素材或来源。各段连续无重叠，总时长匹配要求。

45 秒参考结构：

- 0—5 秒：一个具体问题或动作，立即建立观看理由。
- 5—25 秒：解释关键区别，穿插证据或示例。
- 25—40 秒：说明条件、步骤或实际场景。
- 40—45 秒：给一个可完成的下一步。

中文旁白可先按约 3—4 字/秒估算，再试读，留出阅读材料、停顿和转场时间。不要靠加快配音塞满信息。成稿前检查旁白是否能在指定时长内自然说完。

画面优先用户提供的真实素材、可使用的实景、脱敏材料和解释图。资料截图需要标注具体位置；没有素材则明确列为待提供，不能声称已经拍摄或取得。

字幕强调关键词和条件，不复制满屏旁白。涉及薪资时屏幕要呈现单位、时间范围、税前税后及假设。

## 数字人讲解稿

默认 30—60 秒，固定形象与声音须来自用户已确认素材。没有设定时可以给形象建议，不能把建议说成品牌既有资产。

数字人用于通用问题、流程和证据解读，穿插材料与实景。标注“虚拟讲解员”；合成场景标注“场景示意”。不能冒充真实护士、律师、客户或在地顾问，不给个人资格结论。

交付讲解稿、分镜、资料插入点、身份标识位置和必要的生成提示词。用户仅要求脚本时，不自动消耗资源生成头像、声音或视频。

## 视觉与 AI 提示词

有品牌视觉资产就沿用；没有则给当前内容可选方向，不把某套颜色或字体写成官方标准。

优先清楚呈现信息关系，留出手机端安全区、正文与平台遮挡区域。封面主标题短而明确，页内保持标题层级和证据出处可读。

需要提示词时分开写：画面目的、主体、场景、构图、光线风格、比例、文字留白、真实性边界。不要求图像模型生成可读政策、数字、合同、Logo 或大段中文；这些应后期以可编辑文字或真实资料叠加。

AI 图不能充当医院合作、录取、薪资、获批、客户生活或项目成功的证据。

## 同题跨平台改编

保持事实、核心判断和限制条件一致，改变表达深度：

- 小红书把步骤和检查项展开，便于收藏。
- 抖音保留一个最清晰的区别，以动作和画面推进。
- 视频号补充判断前提及家庭共同决策问题。

同题改编不只是删字、换标题；不要强行把一条内容复制到所有平台。用户只要一个平台时，只交付该平台版本。

## 下一步与咨询承接

知识内容与主动咨询的衔接见 [定位与咨询衔接](consultation-and-positioning.md)。学生与家庭诉求分流，进入正式咨询时说明实际服务及费用，不把公开没有讲清的工作限制留到付费后才揭示。

兴趣内容可以止于欣赏、交流或关注；评论设计从本篇具体场景出发，避免泛泛追问、口令刷屏或虚假奖励。需要时可附可选置顶提问或回复草稿，不自动发布。

每条最多设一个主要行动，也可以只建议自查、收藏或和家人讨论。

原案资料方向：《护理赴奥准备清单》《家庭赴奥规划表》。只有资料真实存在或本次同步制作完成时，才写“领取”。预约入口、免费名额、响应时效、价格和交付内容须已确认；不凭空生成链接或稀缺承诺。

咨询前可建议用户整理学历、职业经历、语言阶段或家庭目标等必要信息。公开评论区不收证件号、完整收入证明、孩子身份资料等敏感材料。

## 审核已有内容

局部修改和版本保护见 [修改与私有资料](revision-and-private-data.md)；用户提供数据后按 [素材与反馈](materials-and-feedback.md) 分析，不凭单条表现直接改写品牌规则。

先指出会影响发布的事实与承诺问题，再给修改稿。区分必须修正与创意建议，保留原文有效信息与用户指定风格。

不要因为原稿没有用某个固定句式就判错；标准检查的是读者是否理解、事实是否可靠、内容是否符合品牌。
